## Chapter 02 - Learning Log :pencil2:

### Overview :brain:
This chapter focused on user input, type conversion, numeric expressions, and how Python handles different data types in calculations.

### What I learned :sparkles:
- how Python handles user input using the `input()` function
- `input()` always returns a string by default
- how to convert strings into numbers using `int()` and `float()`
- basic numeric expressions using operators like `+`, `-`, `*`, `/`, and `%`
- how Python evaluates expressions using operator precedence
- how to use parentheses `()` to control the order of evaluation
- how different data types affect how operators behave (e.g., numbers vs strings)
- how to identify and understand type errors caused by incompatible data types
- how comments work in Python using `#`, and that they are ignored by Python and used only for explanation

### Hands-on practice :computer:
In this chapter, I practiced:
- writing simple programs using `input()` to get user data
- converting user input using `int()` and `float()`
- working with numeric expressions and arithmetic operations
- experimenting with type conversions and observing errors
- building small programs to test different operations
